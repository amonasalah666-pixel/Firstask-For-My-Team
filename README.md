# Python Task

## Task: Find the largest number

Implement the `find_largest()` function in `main.py`.

### Requirements

* The function receives a list of numbers.
* Return the largest number in the list.
* Do not use Python's built-in `max()` function.
* Keep the existing program structure.
* Make sure your solution works with negative numbers too.

### Example

```python
find_largest([4, 12, 7, 19, 3])
```

Expected result:

```text
19
```
